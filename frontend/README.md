# Expense Tracker — Frontend

React + Vite frontend for the Expense Tracker app. See the root `README.md` for the full project description, API endpoints, and environment variable setup.

## Quick start

```
npm install
npm run dev
```

Runs on `http://localhost:5173` by default and expects the backend at the URL set in `VITE_API_URL` (see `.env.example`).
